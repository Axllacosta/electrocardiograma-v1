El electrocardiograma no se cargó

Si ves este aviso, abriste el archivo index.html directamente o el servidor no está en marcha. La aplicación tiene que servirse con Vite:

  1. Abre una terminal en la carpeta cardio-monitor (la que contiene package.json).
  2. Ejecuta npm install la primera vez.
  3. Ejecuta npm run dev y abre la dirección que aparece, normalmente http://localhost:3000.

Usa Chrome o Edge de escritorio: son los únicos que pueden conectar con el Arduino.
